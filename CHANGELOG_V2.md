# Ammu Birthday Website v2: Cinematic Chapters

- No React: vanilla JavaScript, HTML, CSS, Three.js. GSAP used when available from pinned CDN; CSS fallback works offline.
- Full-screen chapters with manual Next/Previous; scrolling stays within the current chapter. Navigation remains clickable.
- Staggered entrance animations, individual wishing cards and sequential wish input steps.
- Source order: home, journey, memories, magazine, ID card, letters, movies, midnight, games, certificates, wishes, cake, gifts, prank gifts, lifetime memberships, guided shop, cart, tracking, finale.
- Website font Great Vibes removed; Fraunces + DM Serif Display + DM Sans instead.
- Shop has sequential category selection, mandatory selection for most categories, optional Skip ONLY for ring and vaddanam. No browse-all catalogue.
- Expanded Midnight Universe with eight staged chat-inspired memories. These are illustrative and do not reproduce private chat transcripts.
- Five extra interactive mini-games, six downloadable designed certificate types; old certificate retained.
- Important: Sending real email and OTPs still requires secure credentials; product requests are not paid retailer purchases. Cake cutting is a custom procedural Three.js interaction, not real-time mesh slicing.
- CDNs for GSAP and Google Fonts can be replaced with locally bundled assets; animations still work with built-in CSS fallback.
